# assets

- `poteto.png`: 512×512 app icon with rounded corners. Use it in docs as `<img src="assets/poteto.png" width="140">`.
- `poteto-128.png`, `poteto-32.png`: smaller sizes (avatar, favicon).
- `poteto-original.png`: the full-resolution square artwork (1254×1254), no rounding.
- `social-preview.png`: 1280×640 card for the GitHub repository's social preview (Settings → General → Social preview).

The artwork is original to this repo and shared under the repo's MIT license.
